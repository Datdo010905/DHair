Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

## Yêu cầu làm việc của người dùng

- Trước mỗi đợt sửa file, mô tả cụ thể thay đổi và chờ người dùng duyệt Allow hoặc trả lời đồng ý. Có thể đọc và kiểm tra code trước khi xin duyệt. Một lần duyệt áp dụng cho các thay đổi và sửa lỗi cần thiết trong phạm vi đã nêu.
- Viết code đơn giản, dễ đọc cho người mới học: đặt tên biến và hàm rõ nghĩa, trình bày JSX thoáng, tránh biểu thức lồng nhau khó hiểu.
- Tách hàm khi giúp logic dễ hiểu hơn; không chia quá nhiều file hoặc thêm lớp trừu tượng không cần thiết.
- Thêm chú thích tiếng Việt ở những đoạn cần giải thích mục đích hoặc cách hoạt động.
- Dùng Tailwind qua NativeWind cho phần lớn giao diện, kết hợp một phần StyleSheet khi phù hợp.
